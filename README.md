# agent-kit

One versioned batch of agent skills and plugin manifests that loads identically
in **Claude Code**, **Codex** and **OpenCode**.

Pin one version, verify one checksum, get the same skills in every harness.

## Status

Scaffold. Nothing is built yet. See [PLAN.md](PLAN.md) for the implementation
brief, and [AGENTS.md](AGENTS.md) for the rules any agent working here must
follow.

## Why it exists

The three harnesses discover skills from different directories and use three
incompatible plugin manifest formats, but they all read the same `SKILL.md`.
Without a shared source of truth the same skill gets copied three times and
drifts three ways.

No single directory serves all three harnesses:

| Path | Claude Code | Codex | OpenCode |
|---|:--:|:--:|:--:|
| `.claude/skills/` | yes | no | yes |
| `.agents/skills/` | no | yes | yes |

So a distribution writes to both. OpenCode reads both and deduplicates by skill
name, so the overlap costs nothing.

## Layout

- `skills/` — canonical `SKILL.md` trees. The only place a skill is authored.
- `vendor/` — verbatim upstream copies, one directory per upstream commit.
- `dist/` — generated by the build. Not committed.
- `plugins/` — one manifest per harness, wrapping the same skills.

## Versioning

`VERSION` holds one semver for the whole batch. `agent-kit.lock.json` records,
per skill, the upstream repository, commit sha, license and per-file sha256.
Releases ship `agent-kit_v<version>.tar.gz` alongside
`agent-kit_<version>_checksums.txt`.
